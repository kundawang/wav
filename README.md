Wav audio file encoder and decoder. See [GoDoc](https://godoc.org/github.com/go-audio/wav) for more details.

The decoder automatically detects both RIFF/WAVE and WAVE64 (Sony Wave64)
containers. WAVE64 support is read-only and covers PCM and IEEE float
content: chunks are located by their GUID, sizes are 64-bit and include
the chunk header, and unknown chunks are skipped using the 8-byte
alignment rules of the format.
